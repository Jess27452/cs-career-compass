# Contributing

Thank you for helping students make better-informed career decisions.

1. Open an issue describing the user need or defect.
2. Create a focused branch from `main`.
3. Add or update tests for behavior changes.
4. Run `pnpm lint`, `pnpm test`, and `pnpm build`.
5. Open a pull request with screenshots for interface changes and migration notes for database changes.

Do not commit secrets, student private data, copyrighted problem statements, or unverified claims that a path guarantees employment.
